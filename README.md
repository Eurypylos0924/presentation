# 발표 표준화

멘토링 발표를 **같은 양식**으로 만들기 위한 로컬 도구입니다.
템플릿 30종 중 필요한 것을 골라 담고, 칸을 채우면 웹 슬라이드가 완성됩니다.
줄글 대신 차트·표·흐름도 같은 시각 자료를 쓰도록 유도합니다.

## 실행

처음 한 번:

```bash
uv sync
```

학원·회사 네트워크에서 `invalid peer certificate` 오류가 나면 이렇게 실행합니다.

```bash
uv sync --system-certs
```

실행 (브라우저가 자동으로 열립니다 → http://127.0.0.1:8765):

```bash
uv run python -m app
```

Windows에서는 `run.bat`을 더블클릭해도 됩니다.

## 사용 순서

1. **새 덱** → 구성 세트 선택 (주간 진행 보고 / 실험·분석 결과 / 문제 해결·결정 요청 / 기술 구조 설명 / 기획·일정 공유 / 빈 덱)
2. 위쪽에 덱 제목, 발표자, 날짜, 회차를 입력합니다 (모든 슬라이드의 바닥글과 표지에 자동으로 들어감).
3. **+ 슬라이드 담기** → 템플릿을 여러 개 클릭해서 고르고 한 번에 담기 (고른 순서대로 들어감).
4. 오른쪽 칸을 채웁니다. 처음에는 예시 화면이 흐리게 보이고, 입력하면 내 내용으로 바뀝니다.
   **예시로 채우기**를 누르면 예시 내용을 넣고 고쳐 쓸 수 있어요.
   - 또는 **📝 메모로 만들기**로 정해진 양식의 메모를 쓰면 덱이 한 번에 만들어집니다 (아래 참고).
5. 왼쪽 위의 **시각화 비율**과 가운데 아래의 **가독성 점검**을 확인합니다.
6. **▶ 발표하기** (또는 F5) → 전체화면 발표. `← →` 이동, `N` 발표 메모, `Esc` 종료
7. **저장**(Ctrl+S)하면 `decks/` 폴더에 저장됩니다. 팀원에게 줄 때는 **더보기 → 파일로 내보내기**, 받은 쪽은 **파일 가져오기**를 씁니다.
8. **더보기 → HTML 파일로 내보내기**: 덱이 `.html` 파일 하나로 저장됩니다. 이 프로그램이 없어도 더블클릭하면 브라우저에서 바로 발표할 수 있어요.
   `← →`/스페이스 이동, `N` 발표 메모, `F` 전체화면, 화면 왼쪽·오른쪽 클릭으로도 넘어갑니다. 빈 슬라이드는 빠지고, 주소 끝의 `#3`처럼 장 번호로 바로 갈 수 있어요.
   멘토님께 드리거나 저장소에 올릴 때는 이 파일을 쓰면 됩니다. (글꼴만 인터넷에서 받고, 오프라인이면 맑은 고딕으로 보여요.)
9. **더보기 → PDF로 저장**: 인쇄 창에서 "PDF로 저장"을 고르고 "배경 그래픽"을 켭니다.

## 템플릿 (30종)

| 분류 | 템플릿 |
|---|---|
| 기본 | 표지, 목차, 구간 표지, 핵심 요약 3줄, 개조식 목록 |
| 진행 현황 | 숫자 강조(KPI), 진행 현황(칸반), 일정 타임라인, 이슈·리스크, 피드백 반영표 |
| 결과·분석 | 차트+해석(막대/선/원형), 비교표, 전후 비교, 숫자 하나 크게, 2×2 우선순위 |
| 구조·설명 | 단계 흐름도, 계층 구조도, 문제→원인→해결, 이미지+설명 |
| 학습·공유 | 개념 카드, 개념 비교(A vs B), 동작 원리, 코드 설명, 논문·자료 요약, 배운 점→적용, 용어 정리 |
| 논의·마무리 | 멘토 질문·결정 요청, 다음 할 일, 회고(KPT), 마무리 |

모든 칸에는 글자 수와 항목 수 제한이 있어서, 넘으면 빨갛게 표시되고 경고가 뜹니다.

**구성 세트:** 주간 진행 보고, 실험·분석 결과, 문제 해결·결정 요청, 기술 구조 설명, 기획·일정 공유, 공부한 내용 공유, 논문·자료 리뷰, 회고·스프린트 정리, 빈 덱

**색상 테마:** 차분한 블루, 세이지, 라벤더, 차콜, 샌드. 오래 봐도 눈이 덜 피로하도록 채도를 낮췄어요.

**코드 설명 슬라이드:** 메모에서는 ```` ``` ```` 로 감싸서 씁니다.
````
# 코드: 캐시 적용 코드
언어: Python
```
cache = {}
def answer(q):
    ...
```
- 1 | 질문 → 답 저장용 딕셔너리
- 4-5 | 이미 본 질문이면 바로 반환
````

## 메모로 만들기 (AI 없음)

정해진 양식으로 쓰면 쓴 내용 그대로 슬라이드가 됩니다. 즉시 만들어지고, 지어낸 내용이 들어갈 일이 없어요.

```
제목: 3팀 6차 멘토링          ← 맨 위: 덱 정보 (제목 / 발표자 / 날짜 / 회차)
발표자: 김철수

# 표지: 로그인 기능 연동 결과   ← '# 종류: 슬라이드 제목' 으로 새 슬라이드
부제: 소셜 로그인 2종 연동 완료  ← '칸 이름: 값'

# KPI: 이번 주 지표
- 정답률 | 86 | % | +15%p | 좋아짐   ← 표 형태 칸은 '|' 로 열 구분 (열 순서대로)

# 차트: 로그인 성공률
계열: 연동 전, 연동 후
단위: %
- 1주차 | 82 | 95
해석: 2주 연속 95% 이상 유지

# 진행 현황
완료:                        ← 목록 칸이 여러 개면 '칸 이름:' 다음 줄부터
- 요구사항 정의
진행 중: 로그인 연동, 검색 개선  ← 한 줄에 쉼표로 써도 됨

# 할 일
- 비밀번호 찾기 | 김철수 | 11/26
```

- 종류 이름은 줄여 써도 됩니다: `KPI`, `차트`, `그래프`, `칸반`, `일정`, `이슈`, `비교표`, `전후`, `흐름도`, `구조`, `문제`, `질문`, `할 일`, `마무리` 등
- 오른쪽 미리보기에 슬라이드가 바로 그려지고, 없는 종류나 넘친 항목은 경고로 알려줍니다.
- **양식 안내**에서 종류를 고르고 **이 종류 예시 넣기**를 누르면 그 종류의 예시가 커서 위치에 들어갑니다.
- **지금 덱을 메모로**: 편집 중인 덱을 메모로 바꿔서 글로 고칠 수 있어요. **더보기 → 메모로 내보내기**로 .txt 저장도 됩니다.
- 쓰던 메모는 브라우저에 자동 저장됩니다.

## AI 설정 (선택, 기본 꺼짐)

AI는 꺼진 상태가 기본이고, 켜지 않으면 AI 관련 버튼이 보이지 않습니다.
켜면 슬라이드 한 장을 줄글로 채우는 기능과, 줄글 전체로 덱 초안을 만드는 기능이 생깁니다.
원문에 없는 숫자가 들어가면 경고를 띄워요.

> GPU 없는 노트북(CPU만)에서 로컬 qwen2.5:7b로 시험해 보니 한 장에 40~180초가 걸렸고, 덱 전체 초안은 5분을 넘겨 실패했습니다. 이런 PC에서는 **메모로 만들기**를 권장합니다.

AI를 쓰려면 `.env.example`을 `.env`로 복사해서 채웁니다.

| 쓰는 방식 | 설정 |
|---|---|
| 로컬 모델 (Ollama 등) | `AI_PROVIDER=openai`, `AI_BASE_URL=http://localhost:11434/v1`, `AI_MODEL=<받은 모델 이름>`, 키는 비움 |
| OpenAI 또는 호환 API | `AI_PROVIDER=openai`, `AI_MODEL=...`, `AI_API_KEY=...` |
| Anthropic API | `AI_PROVIDER=anthropic`, `AI_MODEL=...`, `AI_API_KEY=...` |

`.env`는 깃에 올라가지 않습니다 (`.gitignore`).

## 템플릿 추가하기

`static/slides.js`의 `SLIDE_TYPES` 배열에 객체를 하나 추가하면 됩니다.

```js
{
  id: "my_type", name: "이름", category: "analysis", visual: true, desc: "설명",
  fields: [ { key: "title", label: "제목", type: "text", max: 34 }, ... ],
  sample: { title: "예시" },
  render: (v, ctx) => `<h2 class="s-title">${esc(v.title)}</h2> ...`,
}
```

- 필드 타입: `text`, `textarea`, `select`, `number`, `list`, `rows`, `image`
- 슬라이드는 1280×720 고정 캔버스이고, 스타일은 `static/slide.css`에 있습니다.
- 편집 폼, AI 정리, 가독성 점검은 `fields` 정의만으로 자동으로 따라옵니다.

## 구조

```

app/ai.py        AI 호출 (OpenAI 호환 / Anthropic) + 규칙 기반 대체
static/slides.js 템플릿 정의, 렌더링, 가독성 점검, 구성 세트
static/memo.js   양식 메모 ⇄ 덱 변환 (AI 없음)
static/charts.js SVG 차트 (외부 라이브러리 없음)
static/app.js    편집 화면, 라이브러리, 발표 모드, 저장
decks/           저장된 덱 (JSON)
```
